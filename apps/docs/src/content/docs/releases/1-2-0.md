## Upgrade

```bash
npm install -g scholar-mcp@1.2.0
scholar-mcp --version
```

The GitHub Packages distribution is `@lstudlo/scholar-mcp@1.2.0`. See the
[installation instructions](/getting-started/quick-start/#github-packages-mirror)
for authentication. Restart your MCP client after updating.

Use Node.js 22.14 or newer; Node.js 24 LTS is recommended. The package also
supports Node.js 20.19 and later in the Node.js 20 series.

## Changes

- Both publishing workflows verify the registry version and run the installed CLI.
- HTTP transport includes the upstream response-handling fix and now handles IPv6 loopback origins correctly.
- `year_range` uses `{ "start": 2020, "end": 2024 }`. Arrays are not accepted, and the start year cannot exceed the end year.
- OpenAlex authentication uses a header, keeping API keys out of result provenance URLs. DOI lookups use the same authentication.
- DOI resolution no longer substitutes an unrelated search result when an exact match is unavailable.
- Research merging preserves distinct DOIs, authors, and Unicode titles.
- Author-year citation checks require a matching year as well as an author.
- PDF ingestion skips unnecessary landing-page requests when a PDF URL is known, applies network timeouts and size limits, checks the PDF signature, and releases parser resources after failures.
- Runtime and docs dependencies are updated. Published packages include the MIT license.

## Documentation corrections

The API reference now reflects object schemas and optional inputs with defaults.
Configuration and ingestion guides explain parser fallbacks, process-local job
storage, size limits, and reserved OCR/semantic settings. Section breadcrumbs
link to existing pages.

The website runs on Astro 7 with native Markdown, bundled TypeScript controls,
CSS sticky navigation, and a mobile documentation menu. Search also finds API
parameters and configuration names in page content.

Citation checks remain heuristic. OCR and cloud semantic extraction are not
implemented. HTTP clients share the process's document store; use the server
with trusted clients and appropriate file/network access controls.
