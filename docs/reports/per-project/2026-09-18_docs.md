## Astro 7 refactor

components. Removing the unused integration also removes its build warnings.
Content collections use `astro/zod`; static page URLs remain unchanged.
Search, theme, and copy controls use processed TypeScript modules, following
[Astro script processing](https://docs.astro.build/en/guides/client-side-scripts/).
Only the small pre-paint theme initializer remains inline. CSS sticky positioning
replaces scroll/resize handlers. Search indexes page bodies, with regression
tests for API parameters, ranking, Unicode, and result limits.
